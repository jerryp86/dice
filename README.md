# 星骰 Astro Dice

一個以繁體中文呈現的互動占星骰子網站，提供自我探索與反思的靈感。

## 使用方式

在提問欄輸入想探索的主題，或留白自由擲骰。每次擲出一個行星／交點、一個星座與一個宮位，網站會播放擲骰動畫，並給出個別象徵、整合解讀與可實踐的小步驟。結果可複製或透過裝置分享功能傳送。

## 參考資料

- 12 個占星行星／交點象徵：太陽、月亮、水星、金星、火星、木星、土星、天王星、海王星、冥王星、北交點、南交點。
- 12 星座與火、土、風、水四元素。
- 黃道十二宮位及其常見生活領域。

網站以單一靜態 `index.html` 運作，無需安裝套件或後端服務。

## 使用提醒

星骰是占星象徵的自我探索工具，不是確定預言，亦不構成醫療、法律或財務建議。重要決策請結合現實資訊與專業意見。
